# 家醫科月度跟診

在「PGY / Clerk / 外訓 / 家醫科 排班」分頁操作：

1. 按「當月家醫科人員」，輸入 1–2 位代號，例如 `家醫1、家醫2`。留白表示 0 人，舊月份預設也是 0 人。
2. 按「家醫科指定跟診」，切換人員分頁，逐日勾選上午或下午。同一天可勾選兩個時段，每個月獨立儲存。
3. 請假使用「家醫科請假」。鎖定／解鎖使用班表原有的月曆選單或列表鎖定功能，鎖定範圍仍為整個日期時段。
4. 自動排班後檢查預覽與警告，再套用。家醫科只在指定時段跟診，不套用一般外訓的每週跟診、切片配額，也不自動安排其他部門工作。

跟診優先順序為 **家醫科 ＞ Clerk ＞ 外訓 ＞ PGY**。先滿足家醫科指定時段，再安排 Clerk，接著外訓，最後由 PGY 使用剩餘診位。PGY 的照光／治療室與既有鎖定安排保留。

- Clerk 每個兩週 course 以 **9–11 次跟診、1–2 次切片室**為目標；跨月時保留後續日期的跟診份額。
- 外訓不必指定跟診時段。全月以 **工作日上午／下午時段的一半**為跟診目標，例如 20 個工作日、40 個時段，約排 20 次；每完整週約 4–6 次。國定假日不列入工作日，遇請假、停診或容量不足會提示未達目標。
- 外訓在 1–14 日、15 日至月底各安排一次切片室，約每兩週一次。
- 跟診盡量分散於 course 各天與各週，避免前半段排滿、後半段都放假。診間也依 course 平衡：家醫科、PGY、外訓以當月計，Clerk 以梯次計。

跟診多元性使用「設定 → 門診輪值表」每個星期、上午／下午、診間所填的**醫師名稱**。同一位醫師在不同診間看診仍合併計算，例如週一 101 診與週二 103 診都是 A 醫師，視為跟同一位醫師。

先滿足原有跟診優先順序、次數、公平及 course 時間分布，再盡量增加每個人跟過的不同醫師，減少重複集中同一位醫師；條件相同時才平衡診間。所有人員類別都適用。可調整同時段的診間，必要時也可在同一天早午對調跟診與空閒時段，但每人的每日／每週／course 跟診總數、特殊工作、請假、家醫指定、鎖定與兩位 PGY 的指定時段輪替保持不變。

醫師名稱以目前週模板為準，Clerk 也會參考同一 course 跨月的既有或已鎖定跟診。未填醫師、或同一時段同一診間填了不同醫師時，不猜測醫師身分，也不把它算成新的醫師。只修改醫師名稱也會使舊預覽失效，需重新產生預覽。

指定時段若與請假、停診或鎖定內容衝突，或同時需要跟診的人數超過診位，會顯示未滿足的指定時段。自動排班不覆寫鎖定或過去時段；需先調整衝突設定。月曆中「無診」表示目前沒有開放診間，仍可勾選以保留需求並檢查衝突。

名單與指定時段採差異合併儲存，保留其他電腦在開窗期間新增的不同設定；合併後超過 2 人或代號與同月其他類別衝突時拒絕寫入。改動名單、指定、請假或鎖定後，舊的排班預覽必須重新產生。
