# 院內驗收紀錄模板

本頁是**空白模板，未宣稱驗收通過**。由院內使用者在授權環境填寫；不得為驗收額外寫真實醫囑、寄信或點擊打卡。實際操作依院方核准流程觀察，無法安全測試就填「未驗收」。

對外副本只用匿名電腦／案例代號。病人、帳密、收件人、原始截圖／帳本留院內，不填本頁或 Git。

## 基本資料

| 欄位 | 紀錄 |
| --- | --- |
| 日期／院內紀錄代號 | 待填 |
| 匿名電腦代號／Windows／Python | 待填 |
| 畫面版本／部署來源完整 SHA | 待填；無法核對就註明未知 |
| current.txt 版本／啟動路徑代號 | 待填 |
| HIS 顯示版本（與程式版本分開） | 待填 |
| 候選／正式 CI、fake smoke 證據 | 待填；不等於實機通過 |
| 尚未完成的 Opus review／audit | 待填完整 SHA 或無；空白不算通過 |
| 回退來源及恢復排程紀錄代號 | 待填 |

每項填「通過／失敗／未驗收／不適用（附原因）」及匿名案例、觀察、處理。失敗時暫停該功能，依人工流程處理。

## 驗收項目

| 項目 | 通過條件 | 結果／匿名證據／處理 |
| --- | --- | --- |
| 六支根目錄啟動器 | 正確畫面／版本；各程式維持既有實例行為，座標偵測工具無單例限制 | 待填 |
| 更新／重啟／復原 | 套件與指標配套；操作不被更新中斷；設定及待確認狀態保留 | 待填 |
| F7／F8 | F7 浮動門診顯示／隱藏；F8 快速文字；焦點與權限符合原行為 | 待填 |
| F1–F3／F12 | 授權測試環境核對原病人、目標、兩行 UVB／Excimer、取消及部分完成提示 | 待填；無安全環境則未驗收 |
| PGY／Clerk／外訓／家醫 | 請假、固定、鎖定、定案；一般月照光＋治療室（週三下午僅照光）先於公平／跟診；恰兩位 PGY 月另核對手冊所列特殊模式 | 待填 |

| 會診清單及內容 | 姓名／病歷號不出現在寄出清單或原因摘要；床位、主治、時間與去識別化原因摘要保留 | 待填；不附真實內容 |
| 會診摘要 | 查看不觸發查詢／寄信；未知與空名單、待確認與拒收／寄送端接受分開 | 待填 |
| 打卡／多帳號摘要 | 讀取不明不推論未打卡；點擊待確認不重複；跨日／重啟／官方確認正確 | 待填；不額外點擊 |
| 守護程式 | 程序身分、重啟鎖及登入工作階段正確；受監看程式可能因失去心跳重啟，重啟後待確認狀態保留且不重複動作 | 待填；不保證所有執行中操作免於重啟 |
| 座標偵測 | 座標／顏色正確，關閉後主程式熱鍵正常 | 待填 |
| 安全診斷 | 人工檢視分享副本，無病人、帳密、內文／原始畫面 | 待填 |
| 整包回退演練 | 隔離副本驗證套件與資料相容；最新帳本／待確認保留；捷徑、更新、排程可恢復 | 待填；不能只改指標 |
